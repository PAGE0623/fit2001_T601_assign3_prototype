# FIT2001 Assignment 3 — Team 601

SGD Clinic Portal is an interactive front-end prototype for gestational diabetes monitoring, produced for FIT2001 Assignment 3.

## Run the prototype

1. Download or clone this repository.
2. Open `prototype/index.html` in a modern web browser.
3. No installation, server, or external dependencies are required.

## Prototype functions

- **Administrator:** create, view, update and archive patient records; allocate a doctor.
- **Patient:** record diary readings and receive stable or urgent feedback.
- **System:** display example reminders for an upcoming or missing diary entry.
- **Doctor:** review prioritised patients, send follow-up feedback and record consultation notes.
